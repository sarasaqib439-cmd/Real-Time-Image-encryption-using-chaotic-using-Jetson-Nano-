# Chaotic Maps Image Encryption Dataset

This folder contains results for performing **image encryption and decryption**  for the dataset **VisDrone-DET dataset**.
Specifically the **test-challenge(0.28GB)** dataset is used containing the 1500 images. The dataset is available at:
https://github.com/VisDrone/VisDrone-Dataset?tab=readme-ov-file.
The following chaotic maps methods are used for testing:

- **Henon Map**
- **Tent Map**
- **Lorenz–Rossler Map**

The project is implemented in **MATLAB** and supports batch processing of multiple images using **parallel computing (`parfor`)**.
