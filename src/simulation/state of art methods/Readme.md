# MATLAB Codes for Chaos-Based Image Encryption (Dataset Simulations)

This folder contains **MATLAB simulation codes** developed to reproduce and analyze **state-of-the-art chaos-based image encryption techniques** presented in the following two research papers.

---

## Implemented Research Papers

### 1. Henon and Tent Map Based Encryption
**C. Candan and E. M. Sahin**,  
*“Implementation of Real-Time Image Encryption Using Chaotic Maps in Embedded Systems,”*  
**Journal of Science & Technology**, vol. 11, no. 2, p. 11, 2023.

This paper presents real-time image encryption techniques using **chaotic maps** suitable for embedded systems.  
The following methods from this paper are implemented in MATLAB:

- **Henon Map–based Image Encryption**
- **Tent Map–based Image Encryption**

The implementation includes:
- Chaotic sequence generation  
- Confusion and diffusion stages  
- Decryption for correctness verification  
- Histogram analysis  
- Chi-square statistical analysis  
- Pixel correlation analysis  
- Encryption time analysis  
---

### 2. Lorenz–Rossler System Based Encryption
**E. Berkay and Z. Musayev**,  
*“Chaos-based Image Encryption in Embedded Systems using Lorenz–Rossler System,”*  
**ResearchGate**, vol. 5, pp. 153–159, 2023.

This paper proposes a chaos-based encryption scheme using the **Lorenz–Rossler chaotic system**.  
The following method from this paper is implemented:

- **Lorenz–Rossler Map–based Image Encryption**

The implementation includes:
- Lorenz–Rossler chaotic system generation  
- Channel-wise confusion and diffusion  
- Decryption and reconstruction  
- Histogram, chi-square, and correlation analysis  
- Timing analysis  

---

## Purpose of This Folder

- To **simulate and validate** chaos-based image encryption algorithms proposed in recent literature.
- To provide a **dataset-level experimental framework** for performance comparison.
- To generate **quantitative results** (Chi-square, correlation, encryption time) suitable for academic evaluation and reporting.
